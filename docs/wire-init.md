Livewireには、コンポーネントがレンダリングされた直後にアクションを実行する `wire:init` ディレクティブがあります。ページ全体の読み込みを待たせたくない一方で、ページロード直後にはデータを読み込みたい場合に便利です。

```blade
<div wire:init="loadPosts">
    <!-- ... -->
</div>
```

`loadPosts` アクションは、Livewireコンポーネントがページにレンダリングされた直後に実行されます。

ただし、ほとんどの場合は `wire:init` より[Livewireの遅延読み込み機能](/lazy)が適しています。

## リファレンス

```blade
wire:init="action"
```

このディレクティブに修飾子はありません。
