リアルタイムアプリケーションでは、ユーザーのデバイスがインターネットへ接続されていないことを視覚的に示すと便利です。

たとえばLivewireでブログプラットフォームを作った場合、Livewireが投稿をデータベースへ保存できない状態で、ユーザーがブログ記事を丸ごと下書きしてしまわないよう、オフラインであることを知らせたいでしょう。

そのためにLivewireは `wire:offline` ディレクティブを提供しています。Livewireコンポーネント内の要素へ追加すると、デフォルトでは隠され、接続が失われたときに表示されます。

```blade
<div wire:offline>
    このデバイスは現在オフラインです。
</div>
```

ネットワーク接続が復旧すると、要素は再び消えます。

## クラスを切り替える

`class` 修飾子を追加すると、接続が失われたときに要素へクラスを追加できます。オンラインに戻るとクラスは再び削除されます。

```blade
<div wire:offline.class="bg-red-300">
```

反対に `.remove` 修飾子を使うと、接続が失われたときにクラスを削除できます。次の例では、オフライン中に `<div>` から `bg-green-300` クラスが削除されます。

```blade
<div class="bg-green-300" wire:offline.class.remove="bg-green-300">
```

## 属性を切り替える

`.attr` 修飾子を使うと、接続が失われたときに要素へ属性を追加できます。次の例では、オフライン中「保存」ボタンが無効になります。

```blade
<button wire:offline.attr="disabled">保存</button>
```

## リファレンス

```blade
wire:offline
```

### 修飾子

| 修飾子 | 説明 |
| --- | --- |
| `.class="class-name"` | オフライン時にCSSクラスを追加する |
| `.class.remove="class-name"` | オフライン時にCSSクラスを削除する |
| `.attr="attribute"` | オフライン時にHTML属性を追加する |
